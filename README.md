# Essential Configs

A small personal reference for Linux and terminal fixes that I have needed more than once.

## Contents

- `Ghostty/Greek language in terminal` — locale settings for English system messages with Greek character support
- `Ghostty/config file` — a minimal Ghostty configuration note
- `xps 9320(13 plus) webcam not working/webcam fix` — setup notes for an Intel MIPI camera through `v4l2loopback` and `v4l2-relayd`

These are working notes rather than universal setup scripts. Package names, device paths, and service configuration can differ between distributions and hardware revisions, so each command should be reviewed before use.
